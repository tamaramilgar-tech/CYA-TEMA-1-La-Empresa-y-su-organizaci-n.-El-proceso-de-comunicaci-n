Situación de aprendizaje

Recorrido visual, práctico y evaluable

Incluye teoría resumida, mapa conceptual gráfico con huecos interactivos, prácticas para EVAGD, un test por fase y certificado final.

Qué hace el estudiante

Estudia la fase, realiza la práctica en EVAGD, solicita la verificación docente y, después, completa el test correspondiente.

Cómo avanza

La siguiente fase se desbloquea cuando la fase actual ya tiene práctica registrada, verificación docente y test finalizado.

Evaluación

Cada test ofrece dos intentos. Tras el segundo, se muestran las respuestas correctas. Las preguntas se barajan y cambian entre intentos.
