# Unidad 1 · La empresa y su organización

Proyecto web listo para GitHub Pages.

## Publicación
1. Sube el contenido de esta carpeta a un repositorio.
2. En GitHub activa **Settings > Pages**.
3. Publica desde la rama principal y la carpeta raíz.

## Estructura
- `index.html`, `styles.css`, `script.js`, `app-data.js`
- `assets/mapa-fase1.svg`
- `docente/` con soluciones de prácticas en PDF

## Funcionamiento didáctico
- 8 fases
- 1 test por fase
- prácticas para entregar en EVAGD
- verificación docente necesaria para desbloquear cada test
- progreso guardado en `localStorage`
- certificado final imprimible

## Nota técnica
El código docente no se muestra en pantalla y no está guardado en texto plano. La validación usa una huella hash.
