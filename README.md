# Unidad 1 · La empresa y su organización · El proceso de comunicación

Sitio web estático listo para subir a GitHub Pages.

## Contenido
- `index.html` → estructura principal
- `styles.css` → estilos visuales
- `data.js` → fases, contenidos y bancos de preguntas
- `script.js` → lógica de guardado, progreso, test y certificado

## Publicación en GitHub Pages
1. Sube todos los archivos del ZIP al repositorio.
2. Verifica que `index.html` quede en la raíz.
3. En GitHub Pages, publica desde la rama principal y carpeta `/root`.

## Características incluidas
- 8 fases didácticas
- Guardado automático con `localStorage`
- Mapa conceptual con huecos en Fase 1
- Prácticas por fase con registro de entrega
- Test aleatorios de 15 preguntas con 2 intentos
- Respuestas correctas visibles tras el segundo intento
- Certificado final imprimible con resultados y entregas
