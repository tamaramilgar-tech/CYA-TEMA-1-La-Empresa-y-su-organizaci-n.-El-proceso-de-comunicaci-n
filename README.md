# Publicación en GitHub Pages
1. Descomprime el ZIP.
2. Sube el contenido a la raíz del repositorio.
3. En GitHub Pages, selecciona **main** y **/root**.
4. Espera unos minutos y recarga la URL pública.

La web guarda el progreso del alumnado en el navegador mediante `localStorage`.
Las prácticas se entregan en EVAGD y el test se desbloquea tras marcar la entrega y validar la verificación docente.
